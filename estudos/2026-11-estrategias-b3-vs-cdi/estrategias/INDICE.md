# As 34 estratégias

Ordem do ranking por Sortino do relatório v1. As de spec JSON estão em [specs/](specs/), exportadas do bench exatamente como rodaram (o motor lê o JSON como dados). As de código Python apontam para `engine/backtests/strategies/` neste repo; os backtests rodaram com o código do commit `a5f0c2e`. Os fatores nomeados que as specs usam (`sharpe_mom`, `momentum`...) estão em [engine/backtests/strategies/signals.yaml](../../../engine/backtests/strategies/signals.yaml).
