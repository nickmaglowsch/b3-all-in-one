# b3-portfolio

CLI workspace for B3 fundamental analysis and portfolio management, designed to be driven from Claude Code.

## What this is

A small, opinionated set of Python scripts plus a `CLAUDE.md` that teaches Claude Code how to use them. Data comes from [Fundamentus](https://www.fundamentus.com.br/) (public, free) via the `fundamentus` PyPI package. Portfolio positions come from your **official B3 Excel reports** (`Negociação` and `Movimentação` from the B3 Investidor portal) — you drop the `.xlsx` files into `b3_imports/` and a script parses them.

The whole point is that the heavy lifting (data, math, filters) is in deterministic Python, and Claude is the orchestrator and analyst sitting on top.

## Template privacy

The portfolio data committed here is **synthetic** — `b3_imports/*.xlsx` and the CSVs
derived from them are generated by `tests/golden/make_fixtures.py` so the golden test
suite has something to run on. Nothing in them belongs to a real brokerage account.

In a fresh clone of the template, the following are generated locally and can contain private financial information — keep them out of git:

- `b3_imports/*` — raw B3 Excel exports
- `data/**/*.csv` — positions, trades, cash events, snapshots, watchlists, price caches
- `reports/*` — generated analysis and tax reports
- `http_cache.sqlite` and other local caches

To use the template, clone it, add your own B3 exports to `b3_imports/`, then run the scripts below. Your generated files stay local unless you deliberately change `.gitignore`.

## Setup

You need Python 3.10+ and Claude Code installed.

```bash
git clone <wherever-you-put-this>
cd b3-portfolio
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

Then start Claude Code in the project folder:

```bash
claude
```

Claude Code will read `CLAUDE.md` automatically — that file tells it the project layout, methodology, and conventions.

## Workflows

### First-time portfolio import

1. Log in to B3's investor portal (Área do Investidor).
2. Go to **Extrato → Negociação** and download the longest date range available as `.xlsx`.
3. Go to **Extrato → Movimentação** and download the longest date range available as `.xlsx`.
4. Drop both files into `b3_imports/`. Files in this folder are ignored by git.
5. In Claude Code: `"load my B3 positions"` → it'll run `load_b3.py`. By default this keeps only equity trades (Renda Variável); pass `--all-markets` if you also want to track Tesouro Direto / debentures.

Use both reports when possible: `Negociação` gives the clean trade ledger, while `Movimentação` adds dividends, JCP, FII rendimentos, amortizations, corporate actions, refunds, and custody events. If you see an `incomplete_history` warning, it means the reports don't go back far enough — download longer-range exports.

### Daily ranking session

```
"refresh the snapshot and show me the top 20 by mixed methodology"
"now rank the same snapshot but with weights value=0.5 quality=0.5 growth=0"
"focus on my watchlist only"
```

### Portfolio review

```
"how's my portfolio doing?"
"any holdings that fell out of the top quartile?"
"what's my sector concentration?"
```

### New capital

```
"I have 5000 reais to deploy this month — what would the methodology suggest?"
"same but only names I don't already hold"
```

### Deep dive

```
"deep dive on WEGE3 vs EGIE3 — which has the better quality+value mix?"
```

### IRPF report

To generate a copy-paste-ready IRPF 2026 report for ano-base 2025, use this prompt in Claude Code:

```text
Generate a copy-paste-ready IRPF 2026 report for ano-base 2025.

Use my local B3 data only. First run the portfolio import from the Excel files in b3_imports/, then run the IRPF report generator. Save the final markdown report under reports/ as reports/2026-irpf-ano-base-2025.md.

Make the report practical for filling the IRPF program: Bens e Direitos, dividendos, JCP, rendimentos de FII, renda fixa where available, realized gains/losses, and a final checklist of items I still need to verify against broker informes. Do not invent missing CNPJs or tax values; mark anything uncertain as "verificar no informe".
```

Direct command version:

```bash
python -m scripts.load_b3 --all-markets
python -m scripts.irpf_2026 --year 2025 > reports/2026-irpf-ano-base-2025.md
```

## What the scripts do (cheat sheet)

| Script | Purpose |
|--------|---------|
| `scripts/fetch_fundamentus.py` | Pull full B3 screener → `data/snapshots/YYYY-MM-DD.csv` |
| `scripts/load_b3.py` | Parse B3 Excel files in `b3_imports/` → `data/positions.csv` |
| `scripts/portfolio_status.py` | Current allocation, P&L vs latest prices |
| `scripts/suggest_allocation.py --amount N` | Suggested buys for new capital |
| `scripts/irpf_2026.py --year 2025` | Generate an IRPF 2026 markdown report for ano-base 2025 |

All generated outputs under `data/` and `reports/` are ignored by git.

You can run them directly without Claude:

```bash
python -m scripts.fetch_fundamentus
python -m scripts.load_b3
python -m scripts.portfolio_status
python -m scripts.suggest_allocation --amount 5000
python -m scripts.irpf_2026 --year 2025 > reports/2026-irpf-ano-base-2025.md
```

## Methodology (default)

`methodologies/mixed.py` — value (40%) + quality (35%) + growth (25%). See the docstring there for what goes into each pillar. Filters in `methodologies/filters.py`: minimum 2-month liquidity R$ 1M, P/L in (0, 50), positive ROE, Dív.Bruta/Patrim < 2, no tickers ending in `11` (FIIs/units).

You can override weights per-call. To change defaults permanently, edit `methodologies/mixed.py` and `methodologies/filters.py` — both are short and commented.

## What this does NOT do

- No real-time prices (snapshot-based).
- No options, futures, FII-specific analysis, or fixed income.
- No automatic order execution. You read the suggestions and place orders yourself at your broker.
- No backtest engine. Snapshots accumulate over time, but there's no built-in "how would this strategy have done" simulator yet. (Would be a reasonable thing to add — Claude can help.)
- Not investment advice. This is a tool to help you think, not a recommendation.

## Adding your own methodology

Drop a new file in `methodologies/`, e.g. `dividend.py`, exposing a `score(df, weights=None) -> pd.DataFrame` function the same way `mixed.py` does. Then either ask Claude to use it (`"rank using the dividend methodology"`) or pass it via a flag if you wire it into a script.
